# 怎么让「同学用自己手机扫码答题」真正跑起来

二维码只是一串网址的图形。**手机能不能打开，取决于这串网址是不是公网可访问的**。所以先选一条路，再出码。

---

## 路线 1：问卷星（最稳，推荐正式场合）👍

一次性 10 分钟，之后永久有效，还能在后台看统计。

1. 按《赛博算命_问卷与执行手册.md》第五节「方案 B」把问卷建好并**发布**。
2. 发布页复制问卷链接（形如 `https://www.wjx.cn/vm/xxxxx.aspx`）。
3. 生成二维码，任选：
   - 把链接发我，我 30 秒出图；
   - 或自己运行：
     ```powershell
     cd "C:\Users\Administrator\Desktop\赛博算命问卷"
     python make_qr.py "https://www.wjx.cn/vm/xxxxx.aspx"
     ```
4. 得到的 `qrcode_print.png` 可直接打印，`qrcode.png` 用于投屏。

> 用问卷星时，`quiz.html` 就不需要了；两者是替代关系，不是叠加关系。

---

## 路线 2：把 quiz.html 发到免费公网（视觉最惊艳，30 秒）

H5 里是真随机、有解析动画和揭秘页，比问卷星更好看。

**Netlify Drop（最简单，拖拽即部署）**

1. 打开 `https://app.netlify.com/drop`，用邮箱/微信/GitHub 免费注册登录一次。
2. 把一个只含 `quiz.html` 的文件夹（或直接把文件）拖进页面。
3. 几秒后拿到形如 `https://xxxx-yyyy.netlify.app/quiz.html` 的链接。
4. 把这个链接发我出码，或本地运行 `python make_qr.py "上面的链接"`。

**国内访问更快的替代**：Gitee Pages（需实名）、腾讯云 COS 静态网站、阿里云 OSS、学校/学院服务器 Web 目录。

> 微信里打开未备案域名可能提示「非官方网页」，让同学点「继续访问」即可；正式场合更稳的是路线 1。

---

## 路线 3：本机开服 + 现场同一 WiFi（零账号、零费用）

适合人数不多（≤10 台设备）、场地能提供稳定热点的场合。

1. 现场把这台电脑连上**手机热点**（比校园网稳，校园网常开客户端隔离）。
2. 双击 `serve.bat`：
   - 自动识别本机 IP；
   - 自动用该 IP 重新生成 `qrcode.png`；
   - 自动打开主持人页 `#host`（页面中央就是二维码，投屏即可）。
3. 同学扫码 → 打开 `http://<本机IP>:8000/quiz.html` → 答题。
4. 打不开时按顺序排查：防火墙是否放行 Python → 手机是否在同一热点 → 热点是否限制设备数 → 校园网隔离。

> 缺点：电脑必须全程开着、同一网段、设备数受热点限制；不适合 20 人以上正式场合。

---

## 一句话决策

| 场景 | 选哪条 |
|---|---|
| 正式茶话会、要收数据、人多 | 路线 1 问卷星 |
| 想要最好的现场效果、能接受不收数据 | 路线 2 公网托管 |
| 临时小范围试玩 / 现场断网 | 路线 3 本机开服 |

**任何一条路线定了，把最终链接发我，我立刻把 `qrcode.png` 与 `qrcode_print.png` 换成指向它的正式码，并验证解码结果。**
